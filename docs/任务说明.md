# 任务说明.md —— 旋回地层学双井任务（Harbor 任务包说明）

## 一、学科与研究用途

- **学科**：地球与环境科学（旋回地层学 / 天文年代学 / 古气候学）。
- **研究用途**：训练模型在**陆相湖盆地层记录**中完成"天文信号检测 → 沉积速率估计 →
  405 kyr 调谐 → 沉积间断识别 → 多指标交叉验证 → 多井对比"的完整旋回地层学分析。
  该方法链是当前晚古生代大冰期（LPIA）气候-沉积研究（如风城组等陆相记录）
  的标准科研流程，具有真实科研背景。
- **任务属性**：数值可验证的定量分析任务（非开放式讨论）。

## 二、数据来源、生成机制与授权

- **来源**：无版权争议的**合成数据**（符合"允许有科学依据的模拟数据"条款，非批量随机造数）。
- **生成机制（科学依据）**：
  1. 天文信号按 300 Ma 天文解（La2004 外推 + Waltham 2015）参数合成：405/125/95 kyr
     偏心率、35 kyr 斜率（含 ~170 kyr 振幅调制）、21/18 kyr 岁差——与真实 LPIA 陆相记录
     （Huang et al., 2026 GPC；Wei et al., 2023 EPSL）的信号构成一致；
  2. 噪声按**非平稳 AR(1) 红噪声**（ρ=0.92，σ=2.2→3.5）合成，模拟沉积过程自生噪声；
  3. 两组**自生准周期**（~58–63 kyr、~112–118 kyr）模拟三角洲朵体迁移等局部过程；
  4. **分段沉积速率**（井 A：6→7.5→9→7 cm/kyr 跳变；井 B：5.5→8.5 cm/kyr）模拟沉积环境突变；
  5. **沉积间断**：井 A 五处（210±/480±/130±/260±/90 kyr 量级，各 seed 不同）、
     井 B 两处（其一与井 A 同次区域事件）——模拟湖盆暴露/无沉积时段；
  6. 深度域按 0.5 m 均匀重采样，模拟真实测井记录。
- **随机种子**：seed k 用 20261000+k（数据包内 8 个 seed 变体）；各 seed 的间断时长、
  沉积速率、噪声实现均不同（seed-evolving），真值互不相同，防答案记忆。
- **授权**：全部数据由本任务方自行生成，无第三方数据，可自由用于训练与评测。

## 三、核心难度证据（四连问）

**1. 核心科研瓶颈是什么？**
陆相湖盆记录的天文信号弱、沉积速率非平稳、存在多处间断与强自生噪声——
必须通过"多窗谱（MTM）+ 红噪声置信检验 → 演化类沉积速率估计（eAsm/eCOCO）→
分段 405 kyr 调谐 → 双指标交叉验证 → 双井对比"才能正确作答；
任何单步简化都会导致至少一题超差。
（证据位置：instruction.md 问题 Q1–Q8；data/seed_*/well_A.csv、well_B.csv；
tests/truths.json 各 seed 真值互异。）

**2. 常规方法为何不够？**
- 默认 FFT/白噪声置信 → 会把红噪声低频峰误判为周期（Q1/Q5 错）；
- 假设单一全球沉积速率 → 405 kyr 峰在深度域展宽（24–40 m），波长换算全错（Q1/Q2/Q4 错）；
- 全程平滑调谐、忽略间断 → 间断以下年代模型整体错位 ~0.5 Myr（Q2 容差仅 ±0.05 Ma）；
- 仅用 GR 单指标 → 无法分辨 ~60/~112 kyr 峰是天文还是自生（Q6 错）；
- 不做时代校正用 41 kyr 斜率周期 → Q5 错。
（证据位置：数据构造参数见"二"；错误后果见"四"的容差。）

**3. 错误判断会造成什么后果？**
在真实科研中：年代模型错位会直接导致事件对比（如 CPB 界线、区域气候事件）与
资源评价失真；自生信号误判为天文信号会产生"假周期"文献（对照 Smith 2023
"Orbital Cycle Factory"、Weedon 2022 ESR 对该类错误的系统批评）。
本任务把上述后果**量化**为 8 项数值容差（见"四"），错误即失分。

**4. 如何验证正确性？**
- 真值由数据构造参数解析确定（tests/truths.json），可复现、可仲裁；
- 判分由程序按容差逐项比对（tests/check_answers.py），与参考答案隔离；
- 参考解（solution/solve.R，R+astrochron）按标准流程应得满分；
- 公平性已用 AR(1) 红噪声蒙特卡洛检验逐 seed 验证（solution/fairness_report.json）：
  8 个 seed 的 405 kyr、~60 kyr、~112 kyr 信号均显著高于红噪声 95% 置信线，
  而 CARB 在 57–63 / 108–118 kyr 波段均不显著（Q6 可判）。

## 四、Rubric 与容差

8 项逐项 **0/1** 判分，`reward = 正确项数 / 8`，全部命中视为通过（pass）。

| 项 | 检查内容 | 容差 | 科学权重 |
|---|---|---|---|
| Q1 | 总沉积时长（Myr） | ±0.10 | 0.125 |
| Q2 | 250 m 绝对年龄（Ma） | ±0.050 | 0.125 |
| Q3 | 全部间断（5 处，深度+时长，逐处匹配，不得多报） | 深度 ±3 m；时长 ±50 kyr | 0.125 |
| Q4 | 平均沉积速率（cm/kyr） | ±0.20 | 0.125 |
| Q5 | 斜率主周期（kyr，答 41 判错） | ±2.0 | 0.125 |
| Q6 | 60/112 kyr 成分成因 + CARB 交叉验证（4 布尔） | 全部一致 | 0.125 |
| Q7 | 170 kyr 调幅存在性 + 更强指标 + 因子方向 | stronger_in=CARB；cf>gf；[0.05,1.5] | 0.125 |
| Q8 | 区域性间断（井 A/B 深度 + 时长） | 深度 ±3 m；时长 ±50 kyr | 0.125 |

- 边界样例（已纳入判分逻辑）：空答案 / answers.json 缺失 → 0 分；Q3 数量错误（多报/漏报）→ 0 分；
  Q5 答 41 kyr → 0 分（典型科学错误）；Q6/Q7 仅凭 GR 单指标作答 → 布尔/方向不符 → 0 分。
- 等价解法：凡满足容差的数值结果均满分；不因软件选择（Acycle / Astrochron / 等效库）、
  实现细节或图件风格扣分（判分只读 answers.json）。
- 判分脚本：tests/check_answers.py（与参考答案隔离，只比对 truths.json）。
